# Three homepage directions

All options are Arabic-only, frontend-only, and use self-hosted Noto Sans Arabic with Majarra's violet, deep violet, midnight, electric blue, and luminous purple. Technical labels use a system monospace; no new font packages or external font requests were added. Warm paper and neutral ink provide contrast. Each option is a complete, independently structured homepage rather than a color variation of one template.

## 01 — Expressive editorial

Route: `/ar/home-1` (also the default `/ar`).

A nearly edge-to-edge Arabic wordmark dominates the dark, monochrome architectural opening. Fine columns contain service labels, positioning, and the CTA. A rotated lightweight italic Arabic annotation and drawn underline provide a handwritten-style contrast using the existing font. Light introductory and services sections follow. A large first project leads an asymmetric gallery. Four process columns and a square closing CTA reinforce the graphic direction.

No social proof is fabricated; the supporting hero block explains Majarra's two capabilities instead of presenting invented customers or ratings.

## 02 — Cinematic

Route: `/ar/home-2`.

Full-screen saturated imagery with manually selected visual scenes. A heavy headline anchors the physical lower-left of the desktop composition, while description and actions occupy the lower-right. Thumbnail navigation, corner registration marks, pill controls, and expansive project covers establish a different rhythm. Services expand into content and tags; image-led process chapters sit alongside a sticky introduction.

The reference's orange controls are deliberately translated into Majarra's luminous purple. Imagery is photographic; no showreel exists yet. No audio or video is loaded or implied as available.

## 03 — Swiss editorial

Route: `/ar/home-3`.

A modular dot-field opening, visible grid divisions and registration points, a large neutral-weight headline, and compact monospaced metadata. Four principles replace unsupported metrics. Projects use an indexed two-column system and a full-width third case. Services and process use precise rows with shared column alignment. The closing section is part of the grid, not a floating rounded card.

Noto Sans Arabic remains the display font rather than adopting the reference's Latin Inter. A system monospace provides technical label contrast without introducing another font dependency.

## Shared behavior

- Fixed comparison switcher links all three independent routes, with the current option marked.
- Project buttons open native modal case previews.
- Menu buttons open a fullscreen native modal navigation index.
- Native service/FAQ disclosures support keyboard activation.
- Brief dialogs validate fields and copy a local summary. No data is submitted or stored; copy failure provides a manual-copy field.
- Motion pause is available in the comparison dock; reduced-motion preferences disable decorative animation.
- All sample work is identified as illustrative.
- Responsive layouts use separate mobile composition rules.

Verification: TypeScript and production build. Per the user's request, localhost is not opened or inspected. Visual browser QA remains pending their review.
